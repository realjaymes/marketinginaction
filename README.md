# Marketing In Action
Marketing In Action (MIA) is an execution-first marketing ecosystem for product marketers, growth marketers, founders, business owners and go-to-market (GTM) operators.
This repository contains the source code and supporting assets for the Marketing In Action website.
## What is Marketing In Action?
Marketing In Action helps marketers put marketing into action through:
- Practical templates, playbooks and frameworks
- Execution-focused newsletters and content
- Free tools, such as calculators, an events calendar and a marketing AI tools database
- Community discussions and events
- Applied education via MIA Academy
- Consulting and done-for-you marketing for startups and business owners
- Jobs, hiring, and affiliate programs

The platform is built to reduce the gap between learning marketing and doing marketing.

## Tech Stack
### AI & Vibe Coding
- ChatGPT Custom GPT for vibe coding assistance and build guidance
- Google Gemini in Google AI Studio for multimodal prompting and rapid iteration
- Google Antigravity for AI-powered coding assistance
- Lovable for AI driven website and UI prototyping
- Claude Code for AI-assisted development, code generation, and git workflows
- OpenAI Codex CLI for terminal-based AI code generation and editing
### Development Environment
- macOS for local development
- Visual Studio Code for writing, editing, and reviewing code
- Git CLI on Mac Terminal for commits, branching, merges, and conflict resolution
### Core Web Technologies
- HTML for structure and semantic markup
- CSS for layout, typography, and visual styling
- Vanilla JavaScript for interactivity and lightweight behavior
- Python scripts that check every page before it goes live and keep the sitemap and resource pages up to date
### Version Control & Collaboration
- Git for version control and change tracking
- GitHub for repository hosting and collaboration
- GitHub Actions for weekly upkeep of the resource pages
### Hosting, DNS & Delivery
- Cloudflare Pages for hosting, with every update deployed automatically
- Cloudflare for DNS management, SSL, CDN, and redirect rules
### Content & Publishing
- Substack for newsletter publishing and content management on a custom subdomain
### Analytics & Measurement
- Google Tag Manager for centralized analytics and event management
- Google Analytics 4 for traffic, engagement, and performance tracking
- Meta and TikTok pixels for measuring ad campaigns
